# spotify-song-recommender
Takes a song and recommends 10 more like it.

## Data
1. Download the Spotify 1 Million Tracks dataset from Kaggle: [https://www.kaggle.com/datasets/amitanshjoshi/spotify-1million-tracks]
2. Export your Liked Songs as a CSV with Exportify for songs you prefer (exportify.net)
3. Put both CSV files in a folder called data/
